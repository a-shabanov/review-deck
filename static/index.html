Keyboard controls

Left-hand playback

Space pause / resume

Tab back 2 s · Shift+Tab back 10 s

` forward 2 s · Shift+` forward 10 s

⌥3 slower · ⌥4 faster · ⌥5 1×

⌥Z ⌥C previous / next frame

⌥X delete selected marks

⌥R reverse direction

⌥Tab / ⌥⇧Tab next / previous video

Track hotkeys appear on the left of the timeline; digits can be assigned to less-used tracks.

Right-hand playback

L forward; repeat to speed up · J reverse · K stop

↑ ↓ speed steps 0.1…16× · 6…9 1.5 / 2 / 4 / 8× · 0 1×

← → seek 2 s · Shift 10 s · ⌘ 60 s

, . or ⌥← ⌥→ step one frame

Home End beginning / end

PgUp PgDn previous / next mark

Annotations

Hold a track key (F S D …) to record a time span.

Shift+key latches the start; press again to end the mark.

Click a mark to select it and seek · Del deletes it.

Shift-drag to select a region · ⌘-click to add/remove a mark.

Click a track name to select its visible marks (Shift: entire video) · ⌘A selects all visible marks (⌘⇧A: entire video).

Selection: Del / ⌥X delete · drag to move · ⌥⇧←→ nudge one frame · Esc clear.

Drag a mark to move it; drag an edge to adjust its duration.

⌥⇧← ⌥⇧→ nudge a frame · { } set the start / end to the playhead.

⌘Z undo · ⌘⇧Z redo

O mark video OK · U clear status · X flag a defect in the library.

N video note or caption for the selected mark · I participants and tags

Zoom and framing

= - zoom in / out · \ reset

Wheel / pinch to zoom at the cursor · drag to pan.

Ctrl+arrows pan the frame · [ ] change timeline scale.

Drawings

P pause and draw on the current frame.

While drawing: 1…5 color · [ ] width · ⌘Z undo stroke.

Enter or P save · Esc cancel.

Esc outside a mode returns to the library.

Participants and tags

Library: A participants · T tags · G grouping · ⌘/Shift-click for several videos.

Player: I participants/tags · 📷 uses the current frame and zoom for an avatar.

Changes save automatically in the review data directory. The merged main-timeline export is all.json.

Annotation tracks

Track ID · hotkey (letter, digit, or alt+letter) → label and color. Saved for the entire library.

Enter: add (a new name creates an entry) · ↑↓: select · Backspace in an empty field: remove last · Tab: participants/tags · Esc: close
Grouped tag: “project: Music video”. A partial assignment (2/5) adds the entry to every selected video when clicked.

Changes save immediately. Merge moves video links and the old name (as an alias) into the chosen entry.
